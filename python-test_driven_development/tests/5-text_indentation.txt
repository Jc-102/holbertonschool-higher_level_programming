The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

Import the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

One of each character:
    >>> text_indentation("Hello. How are you? Fine: thanks")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

Spaces at the start and end of lines are removed:
    >>> text_indentation("   Hi.    Bye   ")
    Hi.
    <BLANKLINE>
    Bye

Text ending with a special character:
    >>> text_indentation("End.")
    End.
    <BLANKLINE>

Text with no special characters:
    >>> text_indentation("No punctuation here")
    No punctuation here

Two special characters in a row:
    >>> text_indentation("Wait?.")
    Wait?
    <BLANKLINE>
    .
    <BLANKLINE>

Empty string prints nothing:
    >>> text_indentation("")

text is not a string:
    >>> text_indentation(12)

text is None:
    >>> text_indentation(None)
    Traceback (most recent call last):
    ...
    TypeError: text must be a string

    >>> text_indentation()
